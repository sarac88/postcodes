# postcodes

En este proyecto empecé tomando como referencia la estructura de la aplicación «Recetario» y creando las carpetas necesarias dentro de lib. También incorporé los modelos SearchResponse y Place, generados a partir de los datos de la API.

A medida que avanzaba, fui entendiendo mejor cómo se organiza una aplicación Flutter: las funciones y los estados relacionados con una pantalla pueden estar en el mismo archivo; los estilos y los widgets reutilizables se pueden separar; y FutureBuilder permite gestionar los estados de carga, error y resultados mediante un snapshot. También aprendí cómo conectar la aplicación a una API para obtener datos de Internet.

El apoyo de Copilot me ayudó a avanzar más rápido y a dividir el trabajo en pasos manejables. En algunos casos, simplifiqué el código para que no fuera más complejo de lo necesario. Aun así, considero importante revisar y comprender los cambios, no solo aceptarlos.

En esta época de herramientas de inteligencia artificial, escribir todo manualmente desde cero puede parecer menos habitual. Pero usar estas herramientas también puede ser una oportunidad para aprender, siempre que nos detengamos a entender cómo funciona el código que producen.
